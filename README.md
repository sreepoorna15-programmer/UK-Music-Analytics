# UK-Music-Analytics
# 🎧 UK Top 50 Music Analytics Project
## 📌 Problem Statement
Despite access to daily UK Top 50 playlist data, stakeholders lack clarity on:
- Artist dominance in the UK market
- Preference for domestic vs international artists
- Impact of collaborations on chart performance
- Performance of explicit vs non-explicit content
- Influence of album structure on success
- ## 🛠️ Approach
- Imported dataset using Python (Pandas)
- Performed data cleaning (handled missing values, removed duplicates)
- Conducted exploratory data analysis (EDA)
- Created new features like:
  - Collaboration indicator
  - Artist origin (UK vs International)
- Used visualizations to identify trends and patterns
- ## 📊 Key Insight
- A small number of artists dominate the UK charts
- International artists have strong presence in the UK market
- Collaborative songs generate higher average streams
- Explicit content performs competitively
- Singles tend to perform better than album tracks
- ## 📌 Conclusion
The analysis highlights that data-driven strategies such as collaborations, focus on singles, and targeting global audiences can significantly improve chart performance. The study demonstrates the importance of analytics in decision-making within the music industry.
## 🚀 Tools Used
- Python
- Pandas
- Matplotlib
- Streamlit / Power BI
